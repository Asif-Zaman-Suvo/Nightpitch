# Nightpitch app icons

The PNG icons in this directory are derived from `public/brand-source.png`.
The football trophy mark is used for browser tabs, mobile home screens,
and the web app manifest. `icon-maskable-512x512.png` includes extra padding
for adaptive icon masks.

`app/favicon.ico` contains 16, 32, and 48 pixel versions of the same mark.
The header uses `public/brand/mark.png` and `public/brand/wordmark.png`.
